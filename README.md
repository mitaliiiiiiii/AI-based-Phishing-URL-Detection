Built a Python-Based Phishing URL Detector 🚨

Excited to share one of my cybersecurity mini projects — an AI-Based Phishing URL Detector developed using Python.

This project focuses on identifying suspicious and potentially malicious URLs using heuristic analysis and cybersecurity detection techniques commonly used in SOC environments.

🔍 Key Features:
• Detects suspicious phishing indicators in URLs
• Identifies IP-based and shortened malicious links
• Performs HTTPS security checks
• Detects suspicious keywords such as login, verify, secure, update, banking, etc.
• Calculates risk scores based on URL behavior
• WHOIS lookup integration for domain analysis
• Generates threat analysis results directly in terminal
